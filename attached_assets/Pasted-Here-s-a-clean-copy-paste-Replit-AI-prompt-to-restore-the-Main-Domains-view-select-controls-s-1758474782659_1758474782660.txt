🔧 Replit AI Prompt — Restore “Main Domains” + Control Selection on Regulation page

Context:
Re-add the section on the Regulation detail page that shows Main Domains (e.g., Cybersecurity Governance/Defense/Resilience, etc.), with counts and the ability to drill in and select controls. This was removed; we need it back, reading from the new generic tables via our APIs.

Data contracts (use these exactly)
	•	GET /api/regulations/:id/controls → returns an array of controls with camelCase fields:
	•	id, clauseNumber
	•	domainEn, domainAr
	•	subdomainEn, subdomainAr
	•	controlEn, controlAr
	•	descriptionEn, descriptionAr
	•	evidenceTypes (array or comma string), weight
	•	Optional language toggle en|ar; default to en.
	•	We also have GET /api/regulations/by-code/:code and GET /api/regulations if needed.

What to build (frontend)

Recreate the Regulation Detail page section with:
	1.	Header card (already exists): shows regulation title.
	2.	Search bar (debounced 250ms): filters controls by clauseNumber, controlEn/Ar, descriptionEn/Ar.
	3.	Main Domains grid (this is the missing part to restore):
	•	Compute unique domains from domainEn (and domainAr when lang==='ar').
	•	For each domain, show a card with:
	•	Domain name
	•	Count badge (number of controls in that domain)
	•	Click to open a drawer/modal that lists controls in that domain with:
	•	Checkbox per control
	•	Clause number (if present) + control title
	•	Small description preview (2 lines)
	•	“Select all / Deselect all in this domain”
	•	Sticky footer in the drawer with:
	•	“Selected: N”
	•	Primary action button (configurable label: “Add to Project” or “Create Tasks”)
	4.	Global selection bar (fixed at the bottom of the page, appears when ≥1 selected):
	•	Shows total selected count across domains
	•	“Clear” button
	•	Primary action button (onProceed(selectedControlIds: number[])) — keep this as a prop so the parent flow (project/task wizard) can hook in.

UX/Details

const key = (currentLang === 'ar' ? c.domainAr : c.domainEn)?.trim().toLowerCase();

	•	Evidence list: if evidenceTypes is a string, split by comma; if array, render tags.
	•	Empty states:
	•	No controls → “No controls found for this regulation.”
