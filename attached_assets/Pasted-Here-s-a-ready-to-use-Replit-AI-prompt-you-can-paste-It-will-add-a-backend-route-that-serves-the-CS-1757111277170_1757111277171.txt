Replit AI Prompt — Add CSV Template Download for Regulations

Goal

Create an endpoint /api/admin/regulations/template.csv that serves a UTF-8 BOM CSV regulation template (ECC/DCC layout + 2 sample rows).
Wire the Download CSV Template button in ImportRegulation.tsx to fetch it and trigger a download.

2. Frontend

File: client/src/lib/api/regulations.ts
Add:

export async function downloadTemplate(sample = true): Promise<Blob> {
  const r = await fetch("/api/admin/regulations/template.csv", {
    credentials: "include"
  });
  if (!r.ok) throw new Error(await r.text());
  return r.blob();
}

File: client/src/pages/regulations/ImportRegulation.tsx
Add the button handler:

import { downloadTemplate } from "@/lib/api/regulations";

async function handleDownloadTemplate() {
  try {
    const blob = await downloadTemplate();
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = "regulation-template.csv";
    document.body.appendChild(a);
    a.click();
    a.remove();
    URL.revokeObjectURL(url);
  } catch (e:any) {
    toast({
      title: "Download failed",
      description: e?.message || "Unable to download template",
      variant: "destructive",
    });
  }
}

Wire it to your button:

<Button variant="outline" onClick={handleDownloadTemplate}>
  Download CSV Template
</Button>
