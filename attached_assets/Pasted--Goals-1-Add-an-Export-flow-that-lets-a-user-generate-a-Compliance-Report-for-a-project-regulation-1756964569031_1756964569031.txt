
Goals
	1.	Add an Export flow that lets a user generate a Compliance Report for a project/regulation as:
	•	PDF (print-ready)
	•	Word (.docx)
	•	Excel (.xlsx)
	2.	Include all Controls + per-control status + linked evidence.
	3.	Package evidence files in an optional ZIP bundle with an auditor index (HTML) so auditors can browse evidence easily offline.
	4.	Keep tenant/auth checks + RBAC.
	5.	UX: frictionless—one modal, select scope + format(s) + evidence options, click Export, get a download.
	6.	i18n-ready (EN first; wire a hook to support AR later).

	•	Evidence ZIP bundler: streamBundle({ report, formats, includeEvidence: 'attach'|'link'|'both' })
	•	Use archiver to stream:
	•	Add /reports/Report.<pdf|docx|xlsx> files (generated buffers)

4) Routes

Create server/routes/reports.ts and mount it in server/index.ts (after auth), e.g. app.use('/api/reports', reportsRouter).
	•	RBAC: add export_compliance_reports permission; wire a guard:
	•	In server/rbac-seed.ts: add the permission and map it to Admin/Manager roles.
	•	In server/rbac-middleware.ts: export const requireExportReports = () => requirePermissions(['export_compliance_reports'], true);
	•	POST /api/reports/compliance/export (protected: isAuthenticated, requireExportReports()):
	•	Payload (zod):

{
  projectId: number,
  regulationCode?: string, // e.g., "NCA-ECC-2:2024"
  formats: { pdf: boolean; docx: boolean; xlsx: boolean },

Content-Type: application/zip
Content-Disposition: attachment; filename="Ambersand_Compliance_Report_<project>.zip"

	•	Ensure tenant scoping: validate req.user.organizationId against project’s organization before exporting.
	•	Performance:
	•	For > 300 evidence files or > 250 MB total, fall back to async job:
	•	Create a reports_jobs table (id, userId, projectId, params JSON, status, createdAt, completedAt, filePath)
	•	Spawn the build, then notify via existing email service when ready.
	•	Add GET /api/reports/jobs/:id and GET /api/reports/download/:id.

Security & Limits
	•	Only users with both view_evidence_repository and export_compliance_reports can export.
	•	Sanitize every file name.
	•	Stream files; do not buffer large evidence files in memory at once.
	•	If a file path does not exist, emit a note into the report and skip attachment.

Acceptance Criteria
	•	From Project Detail, clicking Export Report opens a dialog; choosing formats + evidence mode downloads either:
	•	A ZIP containing Report.pdf, Report.docx, Report.xlsx and /evidence/* + /index.html, or
	•	A single file (if link-only & one format).
	•	Controls section lists every control (code, title, domain, status, approver/date) with linked evidence.
	•	Excel has Overview, Controls, Evidence Index sheets with filters + hyperlinks.
	•	PDF is clean A4, print-ready (page numbers, header with logo/name, footer with date).
	•	RBAC enforced; unauthorized users get 403.
	•	Handles projects with 100+ controls, 100+ evidence without timing out (streams/async job used when necessary).
